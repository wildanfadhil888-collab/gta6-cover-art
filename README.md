Offline GTA 6-style cover art maker — turn your photos into multi-panel key-art posters. 6 layouts, 6 gradient-map grades, PNG export 1920×1080 / 1080×1350 / 1080×1080.

## Run it

```sh
node serve.ts
```

Then open `http://localhost:8080`. Build the dossier with `MAKEFUN_OUTPUT_DIR=out node main.ts` after generating the screenshots.
